# Нейтральные креативы предпросмотра

Шесть иллюстраций созданы встроенным Image Gen в одобренном пользователем концепте 17.10.2026. Сохранены только области изображений из первого макета, без текста и элементов интерфейса. Настоящие логотипы не использованы.

Эти файлы подключает только явный `Design_Preview.cmd` / `tools/design_preview.py` к отдельной базе `data/design-preview`. Рабочий каталог не подставляет их вместо реальных изображений объявлений. Предпросмотр помечен «Демонстрационные данные» и не запускает сборщик внешних сайтов.
