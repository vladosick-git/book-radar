# Docker: пример самостоятельного развёртывания

Конфигурация не содержит адресов и учётных данных рабочего сервера.

1. Собрать frontend из корня проекта: `npm --prefix frontend ci && npm --prefix frontend run build`.
2. В каталоге `deploy` скопировать `.env.example` в локальный `.env`. Он исключён из Git.
3. Указать собственный домен в `RADAR_DOMAIN` и `RADAR_ALLOWED_HOSTS`, настроить DNS и доступность портов80/443.
4. Создать хеш собственного пароля через `python -m backend.auth hash`; сохранить его только в `.env`.
5. Создать ключ хранилища в `deploy/secrets/vault.key`. Команда для контейнера приведена в `.env.example`. Настоящий ключ никогда не добавлять в Git.
6. Выполнить `docker compose up -d --build`. Для проверки параметров предусмотрен `check_config.py`.

API и worker используют общий том данных, но разные процессы. Сервис резервного копирования сохраняет копии в отдельный том. Caddy обслуживает HTTPS на домене владельца.

Для локального просмотра дизайна Docker и домен не нужны: используйте `tools/design_preview.py`. Шаблон развёртывания не подтверждает доступность внешних почтовых сервисов или успешный вход на литературные площадки.
