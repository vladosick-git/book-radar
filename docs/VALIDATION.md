# Проверка публичной копии

Исходный снимок: **0.8.2**, проверено17.10.2026. Это портфолио-копия приложения; содержимое рабочих аккаунтов, баз и серверных настроек в неё не включено.

| Проверка | Результат |
|---|---|
| Python | 287 тестов PASS; одно предупреждение о будущем изменении Starlette/httpx |
| Frontend | `npm ci` и `npm run build` PASS |
| Браузер | Chromium Playwright:1600×1200,1024×1366 и390×844 |
| Содержимое страниц | Заголовок/содержимое PASS, пустых экранов и Vite overlay нет |
| Консоль | Ошибок и предупреждений приложения нет |
| Адаптив | Горизонтальных переполнений на проверенных ширинах нет |
| Поиск и фильтры | Кириллический поиск, фильтр рекламодателя, сохранение фильтра в экспорте PASS |
| Карточка | Открытие, Escape и возврат фокуса PASS |
| Выгрузка | Реально скачанный CSV содержит4 строки, соответствующие выбранному рекламодателю |
| Внешние запросы при съёмке | 0; показ использует отдельную локальную базу |
| Секреты | Локальный Gitleaks8.30.1: обнаружений нет; дополнительно проверен состав файлов публикации |

Семь исходных снимков интерфейса находятся в [screenshots/](screenshots/). На планшетном снимке сохранена вся страница; остальные показывают выбранный viewport. Демонстрационные счётчики и статусы не являются результатами работы с реальными сайтами.

Отличия публичной поставки: клиентская документация и настройки исключены; история Git начинается с чистого снимка; миграционная фикстура поставляется в SQL и восстанавливается тестами; примеры объявлений и профилей вымышленные. Секреты и браузерные сессии пользователь создаёт у себя.

В репозитории есть GitHub Actions для повторной сборки и тестов. Отдельный прогон Docker, внешней почты и реальных аккаунтов в рамках подготовки портфолио не выполнялся. Это проверка публичного пакета и интерфейса, а не полный аудит безопасности.
